# 大嵓埜 ／ 月替わりコース Reel

5月（第2木曜投稿用）の Instagram Reel 用 mp4。
旬の鮮魚を確かな腕で仕込む高級和食店のコース紹介。

- 出力: `dist/reel.mp4` （1080×1920 / 30fps / H.264+AAC / 約43.2秒）
- 用途: Instagram Reel（9:16）
- BGM: `Porcelain_and_Pine.mp3`（リポジトリ同梱、`-stream_loop -1` で動画長に合わせて自動ループ＋頭尻フェード）

## 構成（絵コンテ）

| #  | 時間 (s)    | 内容                                       |
|----|-------------|--------------------------------------------|
| 1  | 0.0 – 5.0   | タイトル「五月 月替わりコース／旬を、極める。」（メイン文字を右に120pxシフト） |
| 2  | 5.0 – 9.6   | 調理0008（ズームイン）                       |
| 3  | 9.6 – 14.2  | 調理0010（パンアップ）                       |
| 4  | 14.2 – 18.8 | 調理0049（パン右）                           |
| 5  | 18.8 – 23.4 | 調理0054（ズームイン）                       |
| 6  | 23.4 – 28.0 | 造里0008（ズームイン）                       |
| 7  | 28.0 – 32.6 | 造里0020（ズームアウト）                     |
| 8  | 32.6 – 37.2 | 造里0039（パンダウン）                       |
| 9  | 37.2 – 43.2 | 予約QR＋「ご予約はこちらから」                |

各カットは Ken Burns 風（緩やかなズーム・パン）＋ヴィネット＋彩度落としで高級感を維持。
各フレームに左上ブランドロゴ「大嵓埜 / OOKURANO」を焼き込み。

## ビルド方法

```bash
# 依存: ffmpeg, fonts-noto-cjk, python3 + Pillow
python3 scripts/make_titles.py     # テロップPNGを生成（build/titles/）
bash scripts/make_reel.sh          # 各クリップ→連結→BGM合成→mux
# → dist/reel.mp4
```

## 差し替えポイント

- テロップ文言: `scripts/make_titles.py`
- カット順・尺・カメラワーク: `scripts/make_reel.sh` の `make_clip` 呼び出し
- 色味: `make_clip` 内 `eq=` と `curves=`
- BGM: スクリプト末尾の `sine`/`anoisesrc` の周波数・ボリューム
